# 参考项目

早期探索比较了下列项目。这里记录学习方向，不声明兼容某个当前版本，也不将其代码合并到本仓库。

| 项目 | 参考方向 |
| --- | --- |
| [DeepTutor](https://github.com/HKUDS/DeepTutor) | 教学、知识库和掌握度学习流程 |
| [Open Notebook](https://github.com/lfnovo/open-notebook) | 本地资料组织、笔记和带来源的问答 |
| [PageLM](https://github.com/CaviraOSS/PageLM) | 题目、闪卡等学习形式 |
| [Koodo Reader](https://github.com/koodo-reader/koodo-reader) | 目录、标注和阅读体验 |
| [MinerU Document Explorer](https://github.com/opendatalab/MinerU-Document-Explorer) | 文档解析、检索与原文证据 |
| [OpenTutor](https://github.com/zijinz456/OpenTutor) | 学习计划与导师式交互 |

本地探索也使用过名为 OpenMAIC 的课程界面；尚未核实该副本的上游来源，因此不填写猜测的仓库地址或作代码归属声明。

若未来引入第三方代码，应先核对对应版本的许可证、保留版权声明，并说明具体复用范围。当前仓库的 MIT 许可证只覆盖本项目有权发布的内容。
