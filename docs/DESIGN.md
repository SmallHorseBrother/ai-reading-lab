# 从资料总结到主动学习

目标是帮助学习者解释、应用和检验书中的观点，而不是把“生成了摘要”当作“已经学会”。

当前代码提供一个小闭环：读取资料 → 形成单元 → 选择讲解深度 → 回答问题 → 获得反馈 → 安排复习。

## 当前实现

- 原文保留在本地输入文件中。
- 使用可配置的 OpenAI 兼容接口生成内容。
- L1/L2/L3 表示讲解深度，而不是题目的心理测量难度。
- 评分反馈会影响课程级深度和复习日期。
- 学习数据保存在本地 JSON 和 Markdown 中。

## 下一步设计

1. **全书地图**：概念之间如何关联，这本书解决哪些问题。
2. **学习诊断**：区分“见过术语”“能解释”“能应用”。
3. **个性路线**：已掌握的略过，关键但陌生的展开。
4. **概念练习**：使用新案例检验迁移能力，而不是重复原题。
5. **原文锚点**：区分作者观点、证据和模型扩展。
6. **薄弱点复习**：按概念记录回答、信心及复习结果。

建议先在一份原创短文本上完整验证，再扩大到长书和跨书比较。未来的数据模型可以围绕 `Book → Concept → SourceAnchor → Attempt → Mastery → RouteDecision` 建立；这些对象目前尚未实现，不应与现有功能混淆。
